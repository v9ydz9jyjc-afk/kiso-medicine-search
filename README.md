# 🌸 基礎的医薬品かんたん検索

厚生労働省が公開する「基礎的医薬品対象品目リスト」と「基礎的リスト」を、スマートフォンでも検索しやすくした非公式サイトです。

## 公開方法（スマホ）

1. このフォルダの**中身をすべて**GitHubリポジトリ直下へアップロードします。
2. GitHubでリポジトリを開き、`Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` を **GitHub Actions** にします。
4. 上部の `Actions` を開き、`Deploy GitHub Pages` が成功するまで待ちます。
5. `Settings` → `Pages` に表示されたURLを開きます。

> ZIPそのものではなく、解凍後の `index.html`、`style.css`、`app.js`、`data`、`scripts`、`.github` などをアップロードしてください。

## 自動更新

- GitHub Actionsが毎日、日本時間5:17ごろに厚生労働省の最新ページを確認します。
- 年度に応じた厚生労働省ページを自動で探し、ページ内の資料リンクも自動検出します。
- 取得件数が急減するなど異常を検出した場合は処理を失敗させ、既存データを上書きしません。
- 更新失敗時は、GitHubリポジトリの `Issues` に警告を自動作成します。

## 表示上の注意

「基礎的医薬品」と「基礎的リスト掲載」は別の情報です。本サイトでは別々に表示します。調剤・変更可否・請求等の最終判断には、最新の厚生労働省資料、通知、レセコン等を使用してください。
